Localised

com.alecdorrington.megalingual.Localised
See theLocalised companion object
final class Localised[+A]

What an app has in each language it supports, such as its interface's text. A language outside them is read in the nearest one: its first supported variety, else its parent's nearest, else the default.

The languages are a partial function's domain, so that an app names only those it supports, never every Language, and what it has in one is made only once that one is read.

def negotiate(chosen: Option[Language], preferences: Seq[Language]): Language

Chooses the language a reader reads in. Their choice comes first, read in its nearest supported language. Then each of their preferences in turn, if it or a variety of it is supported, before any is read in its parent's, so that a language the reader names is never passed over. A broader language is read in a variety the reader also prefers (English is American English to a reader preferring en-US). Else the default.
