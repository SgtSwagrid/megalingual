Language

com.alecdorrington.megalingual.Language
See theLanguage companion object
trait Language

A language, perhaps a variety of another.

Languages form a tree of any depth: a language's parent is the broader language it is a variety of (British English of English), and nothing is read from a code's shape. A broader language is read in its first variety where a more specific one is needed.

Each language is an object saying all there is of it, most simply a Language.Root or a Language.Variety, which takes from its parent what it does not say. Megalingual's own are each in a file of its own in the languages package, Languages.builtIn lists them, and this companion holds each as a language (Language.German). Another library adds its own in Languages of its own, given where languages are looked for. It declares each at the top level, or within an object: within its own body, Scala matches an object nested in a class as anything, so its names would give every language its own name.

An app supporting only some languages says so with a Localised, and never matches on every language itself, so that a language added breaks no app.
