enum Language(val code: String, val direction: Direction, val parent: Option[Language] = ...)

A language, perhaps a variety of another.

A language, perhaps a variety of another.

Languages form a tree of any depth: a language's parent is the broader language it is a variety of (British English of English), and nothing is read from a code's shape. A broader language is read in its first variety where a more specific one is needed.

An app supporting only some languages says so with a Localised, and never matches on every language itself, so that a language added here breaks no app's build.

Value parameters

code

The language's BCP 47 tag, as specific as tells it from the others (en, en-GB, es-419). A variety's need not begin with its parent's.

direction

The direction the language is written in.

parent

The language this is a variety of, if any, declared before it.

final class Localised[+A]

What an app has in each language it supports, such as its interface's text. A language outside them is read in the nearest one: its first supported variety, else one in the same script, else its parent's nearest, else the default.

What an app has in each language it supports, such as its interface's text. A language outside them is read in the nearest one: its first supported variety, else one in the same script, else its parent's nearest, else the default.

The languages are a partial function's domain, so that an app names only those it supports, never every Language, and what it has in one is made only once that one is read.
