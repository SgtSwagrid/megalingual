trait Language

A language, perhaps a variety of another.

A language, perhaps a variety of another.

Languages form a tree of any depth: a language's parent is the broader language it is a variety of (British English of English), and nothing is read from a code's shape. A broader language is read in its first variety where a more specific one is needed.

Each language is an object saying all there is of it, a Language.Root or a Language.Variety, which takes from its parent what it does not say. Megalingual's are all there are, each in a file of its own in the languages package: Language.all lists them, and this companion holds each as a language (Language.German).

An app supporting only some languages says so with a Localised, and never matches on every language itself, so that a language added breaks no app.

final class Localised[+A]

What an app has in each language it supports, such as its interface's text. A language outside them is read in the nearest one: its first supported variety, else its parent's nearest, else the default.

What an app has in each language it supports, such as its interface's text. A language outside them is read in the nearest one: its first supported variety, else its parent's nearest, else the default.

The languages are a partial function's domain, so that an app names only those it supports, never every Language, and what it has in one is made only once that one is read.
